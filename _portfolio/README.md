# `_portfolio`

Portfolio collection. One file per item, **hand-written**. `.md` files are parsed as
Markdown; `.html` files are parsed as HTML.

Required front matter: `title`, `excerpt`, and `collection: portfolio` (other fields
such as `venue`, `date`, `permalink` are optional; the URL pattern
`/portfolio/<path>/` comes from `_config.yml`).

Items appear on the portfolio archive page `_pages/portfolio.html`.
