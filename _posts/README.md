# `_posts`

Blog posts. One file per post, **hand-written**. Filenames **must** be
`YYYY-MM-DD-title.md` — the leading date drives the `date` field and the sort order.

Posts inherit `layout: single` and defaults (comments, share, related) from
`_config.yml`. Front matter `title` is required; `tags` / `categories` are optional.

The sample posts currently in this directory are template placeholders — delete them
and add your own. Drafts can be kept in `_drafts/` until ready.
